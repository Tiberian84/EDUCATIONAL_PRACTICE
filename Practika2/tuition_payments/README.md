# Учёт оплаты обучения

Консольная программа ведёт договоры на обучение: начисления, оплаты, задолженность и просрочку. Журнал хранится в JSON на этом компьютере.

Номер карты, срок действия и код подтверждения программа не спрашивает и не сохраняет. Способ оплаты выбирается из списка: СБП, банковская карта или банковский перевод.

## Возможности

- добавить договор студента;
- добавить начисление за семестр или дополнительную услугу;
- зарегистрировать оплату;
- посчитать задолженность;
- погашать начисления с самого раннего срока;
- показать должников и просроченные начисления;
- сохранить журнал и открыть его при следующем запуске.

## Структура

```text
tuition_payments/
     main.py          # меню и запуск
     ledger.py        # договоры, начисления, оплаты и расчёт долга
     storage.py       # сохранение журнала
     input_utils.py   # проверка ввода
     tests/
         test_ledger.py
         test_storage.py
     data/            # журнал создаётся при сохранении
```

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.

```bash
python main.py
```

Демонстрационные договоры, без реальных студентов:

```bash
python main.py --demo
```

Свой файл журнала:

```bash
python main.py --data data/my_ledger.json
```

Даты вводятся в формате `ДД.ММ.ГГГГ`. Суммы вводятся в целых рублях.
