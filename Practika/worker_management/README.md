# Worker Management

Учебный проект на Python для выполнения задания по производственной практике.

## Описание

Программа реализует простую систему управления списком работников:

- добавление работников вручную;
- добавление работников через готовые фабричные методы;
- изменение данных сотрудника;
- удаление сотрудника;
- вывод всех работников;
- поиск работников, чей стаж работы превышает введённое значение.

Проект построен с учётом индивидуального задания:

- класс вынесен в отдельный модуль;
- для хранения объектов используется список;
- предусмотрены методы отображения и изменения данных;
- реализован ввод данных с клавиатуры и вывод результата по условию задачи.

## Структура проекта

- `main.py` — точка входа в программу, меню и пользовательский ввод;
- `worker.py` — класс `Worker` и вспомогательные методы создания объектов.

## Основные возможности

Класс `Worker` хранит следующие данные:

- ФИО работника;
- должность;
- зарплату;
- год поступления на работу.

Также в программе есть готовые варианты создания работников по ролям:

- менеджер;
- разработчик;
- дизайнер;
- аналитик.
